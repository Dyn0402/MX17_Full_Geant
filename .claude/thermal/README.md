# Thermal (sub-keV) campaign — concluded

**Result (2026-06-10/11, run B sub-keV, 10⁹ events):** the sub-keV X17
measurement is infeasible. Below 1 keV the ³He gas is opaque to (n,p)t,
capping radiative captures at σ_nγ/σ_np ≈ 10⁻⁸ per beam neutron →
**0.06–0.11 X17/day**, a factor 50–100 below the rate table. Agreed with
the collaboration; the ROI moves to the MeV region (see `../mev/`).
Independently confirmed by the fullrange run (2 direct events < 1 keV →
0.09 capt/pulse, dead-on).
